# SM Currency Exchange

A free static currency-converter website.

## Files
- `index.html` — website structure
- `style.css` — responsive design
- `script.js` — currency conversion logic

## Free deployment with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, for example `sm-currency-exchange`.
3. Upload these three files.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/root`.
6. Save.
7. GitHub will provide a free `github.io` website address.

## Exchange-rate source
The JavaScript uses the public Frankfurter API. Check its current documentation and terms before commercial use.

## Important
This is an informational currency converter. It does not process payments, exchange money, hold funds, or execute remittance transactions.
